Exhaustive list of every atomic feature implemented in the Canopy platform.
Last updated: 2026-08-07

## 1. Authentication & Authorization

### 1.1 User Registration
- Email-based account creation with first name, last name
- Password strength validation (minimum 8 characters, uppercase, lowercase, number)
- Client-side password strength meter (4-level leaf indicator)
- Terms and privacy policy acceptance checkbox
- Server-side validation with express-validator
- Strict rate limiting on registration endpoint
- JWT access token (15 min) + refresh token (7 days) issuance
- Session creation in MongoDB on registration

### 1.2 User Login
- Email/password authentication
- "Remember me" checkbox
- Client-side form validation
- Server-side credential verification
- Access token + refresh token return
- Redux auth state initialization
- Redirect to stored destination after login

### 1.3 Logout
- Refresh token blacklisting in MongoDB
- Session revocation
- Client-side token cleanup (localStorage)
- Redux auth state reset

### 1.4 Password Reset Flow
- Forgot password: email submission with rate limiting
- Password reset token generation and storage
- Reset password email sending via Nodemailer
- Reset password page with token validation from URL
- New password with confirmation field
- Password strength requirements enforcement
- Success/error feedback UI

### 1.5 Change Password (Authenticated)
- Current password verification
- New password with confirmation
- Minimum 8 character enforcement
- Success/error feedback

### 1.6 JWT Authentication Middleware
- Bearer token extraction from Authorization header
- Access token verification
- User loading from database
- Request attachment of user object

### 1.7 Refresh Token Flow
- Refresh token endpoint with rate limiting
- Token rotation (new access + refresh tokens)
- Old refresh token invalidation

### 1.8 Role-Based Access Control (RBAC)
- Six roles: public, citizen, ranger, researcher, rescue, admin
- roleGuard middleware for route protection
- Per-route role requirements
- Mission-level role guard (lead, co-lead, member)

### 1.9 Session Management
- List all active sessions for authenticated user
- Session metadata (browser, OS, IP, timestamps)
- Revoke individual session
- Revoke all sessions (logout from all devices)

### 1.10 User Profile Management
- View own profile
- Update first name, last name, phone, organization
- Profile photo upload via multipart/form-data
- Avatar display with initials fallback

### 1.11 Role Request System
- Submit request for elevated role (researcher_ngo, ranger, rescue_center_staff)
- Document upload (PDF, DOC, DOCX, images, max 10MB)
- Invite code support for accelerated approval
- Admin review and approval/rejection
- Rejection reason requirement
- Role profile activation after approval
- Role-specific profile forms:
  - Researcher/NGO: org name, org type, position, website, phone, qualifications, specializations, bio
  - Ranger: department, designation, badge/employee ID, phone, qualifications, experience
  - Rescue Center Staff: center name, center address, center role, phone, qualifications, certifications

### 1.12 Invite Code System
- Admin-generated invite codes with expiry
- Code status tracking (active, used, expired)
- Public invite code validation endpoint
- Invite code redemption during role request
- Code listing for admins

### 1.13 Protected Routes
- Client-side ProtectedRoute component
- Role-based route guards (allowedRoles prop)
- Redirect to login for unauthenticated users
- Redirect to home for unauthorized roles

## 13. ML-Powered Features (via ML Service Proxy)

All ML endpoints are proxied through `/api/ml/*` on the backend, which forwards to the Python FastAPI ML service at `http://localhost:8000`.

### 13.1 Species Image Identification
- Upload image for species classification
- EfficientNet-B0 model (20 Indian wildlife species classes)
- Top-K predictions with confidence scores
- Model weights: `models/species_classifier_best.pth`
- Class mapping: `models/species_classes.json`

### 13.2 Camera Trap Triage
- Upload camera trap image for automated triage
- 4-class classification: animal, person, vehicle, blank
- EfficientNet-B0 model
- Top-K predictions display
- Model weights: `models/camera_trap_classifier_best.pth`
- Class mapping: `models/camera_trap_classes.json`

### 13.3 Bioacoustic Species Identification
- Upload audio file for bird species identification
- BirdNET-analyzer integration
- Configurable species list
- Segment-level predictions with timestamps
- Confidence filtering
- Species list file: `models/bioacoustic_species.txt`

### 13.4 Threat Audio Detection
- Upload audio for threat sound detection
- 2-class classification: threat, non_threat
- YAMNet or simple 1D CNN model
- Model weights: `models/threat_audio_classifier_best.pth`
- Class mapping: `models/threat_audio_classes.json`
- Auto-tip creation on high-confidence threat detection (≥0.7)
- In-app + email notification on threat detection

### 13.5 Habitat NDVI Monitoring
- Draw region on map for NDVI computation
- Sentinel-2 L2A tile search via Planetary Computer STAC API
- Cloud cover filtering (configurable max %)
- Red (B04) and NIR (B08) band extraction
- NDVI computation per tile: (NIR - Red) / (NIR + Red)
- Summary statistics: mean, min, max, median, std, valid pixels, total pixels
- NDVI interpretation guide (bare soil → lush vegetation)
- Multi-tile aggregation

### 13.6 Poaching Hotspot Detection
- Kernel Density Estimation (KDE) on geospatial points
- Configurable bandwidth and grid size
- Fallback to Tips + Sightings database if no points provided
- GeoJSON FeatureCollection output with intensity values
- Top-N hotspot summarization
- Requires ranger, admin, or researcher role

### 13.7 Population Forecasting
- Prophet-based time series forecasting
- Input: historical sightings with timestamps
- Daily count aggregation
- Configurable forecast periods (default 30)
- Seasonality mode configuration
- Forecast with confidence intervals (yhat, yhat_lower, yhat_upper)

### 13.8 Anomaly Detection
- Rolling z-score anomaly detection on daily sighting counts
- Configurable window size and threshold
- Spike/drop direction classification
- Bounding box geo-filtering of sightings
- Date range filtering
- Requires admin or researcher role

### 13.9 Movement Corridors
- GPX file upload and parsing
- CSV file upload and parsing (latitude/longitude columns)
- Flexible column name detection (lat, latitude, lng, lon, etc.)
- Timestamp extraction from GPX/CSV
- GeoJSON LineString output
- Point count tracking

### 13.10 Wildlife Trade Scanner
- Text scanning for illegal wildlife trade indicators
- Keyword-based classification with 30+ keywords
- Confidence scoring (0.0–0.95)
- Matched keyword extraction
- Case-insensitive matching
- Trade flag creation on flagged results
- Persistent storage in MongoDB (TradeFlag model)

### 13.11 Trade Flag Review Queue
- Admin view of all flagged trade listings
- Filter by status: pending, approved, dismissed
- Paginated flag listing
- Approve/dismiss actions
- Review notes field
- Flag detail with source, text, matched keywords, confidence
- No autonomous enforcement action — human review required

## 14. ML Training Infrastructure

### 14.1 Dataset Preparation Scripts
- `prepare_dataset.py` — iNaturalist API image download for species classifier
- `prepare_dataset_gbif.py` — GBIF API image download for species classifier
- `prepare_dataset_v2.py` — iNaturalist with scientific name search
- `fetch_missing.py` — Targeted download for missing species classes
- `fetch_missing_v2.py` — v2 targeted download
- `prepare_camera_trap_dataset.py` — Synthetic image generation for camera trap (animal, person, vehicle, blank)
- `prepare_threat_audio_dataset.py` — Synthetic audio generation for threat audio (non_threat, threat)

### 14.2 Training Scripts
- `train_species_classifier.py` — EfficientNet-B0 fine-tuning for 20 species classes
- `train_camera_trap.py` — EfficientNet-B0 fine-tuning for 4 camera trap classes
- `train_threat_audio.py` — 1D CNN or YAMNet training for 2-class audio classification

### 14.3 Training Features
- Train/validation split (80/20)
- Best model checkpoint saving
- Class mapping JSON export
- Device auto-detection (CUDA/CPU)
- Progress logging (loss, accuracy per epoch)
- Early stopping on best validation accuracy

- Default src, script src, style src, img src, connect src, font src, object src, media src, frame src restrictions

### 15.2 MongoDB Sanitization
- express-mongo-sanitize middleware
- Prevention of NoSQL injection attacks

### 15.3 Rate Limiting
- Global rate limiter: 100 requests per 15 minutes
- Strict rate limiter for sensitive endpoints (auth, tips, role requests, missions, articles)
- Configurable per-route limits

### 15.4 CORS Configuration
- Configurable allowed origin
- Credentials support
- Method and header whitelisting
- Max age preflight cache

### 15.5 Input Validation
- express-validator on all routes
- Email format validation

- Float/range validation for coordinates
- ISO8601 date validation

- Optional field handling

### 15.6 File Upload Security
- File type validation (images, audio, documents)
